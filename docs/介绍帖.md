# 蛋蛋中心：五个产品，都住在 dandanhub.vip

[dandanhub.vip](https://dandanhub.vip) 是蛋蛋中心，一个把几件小工具放在同一个地址下的产品首页。

打开浏览器就能用的，直接进对应页面。需要常驻桌面的，在工具箱里下载 Windows 安装包。每个工具只解决一件具体的事：把照片变成能照着拼的图纸，把今天要记的事留在桌面上，看清一次 Agent 到底调用了什么，给作品加上自己的水印，根据画面写出能直接发的文案，或者在项目里接入一套 Vue 3 组件库。

做这些工具时盯着三件事：功能收小，数据能留在本地就留在本地，打开的时候不要冷冰冰。

现在能用的有五个。

## Pindou 拼豆工坊

地址：[dandanhub.vip/pindou/](https://dandanhub.vip/pindou/)

把照片、插画做成带色号的拼豆图纸。上传、像素化、配色、精修、导出都在网页里完成，不用安装。核心功能免费。

**怎么用**

1. 把图片拖进工作台，也可以点击选择或直接粘贴，支持 WebP。工作台里还能粘贴小红书分享文案或短链，解析出图集后再选一张进入流程；解析失败时，把图片存下来手动上传即可。
2. 选定色卡和格数。品牌色号支持 MARD、COCO、漫漫、盼盼、咪小窝，也可以自己做色板。色板预设有全色系、168 色、96 色。照片和卡通会走不同采样：卡通用主导色，照片用平均色。上传后会按 29 / 58 / 87 拼板给一个建议格数，格子最宽可以拉到 256。
3. 生成后在编辑器里改。可以调亮度、对比度、饱和度，限制最大颜色数来控制要买多少色，照片还可以开降噪和锐化。画笔用来换色、填充，也支持水平或垂直翻转、自动裁掉多余边缘。
4. 导出带色号的 PNG、采购清单（含包数估算），或 PDF。大图可以按 29×29 分板打印成多页，每页带板坐标，拼的时候对得上。

工作台之外还有几条路：画廊里放了卡通、花卉、风景、头像等可编辑案例，点开就能进工作台；[拼豆教程](https://dandanhub.vip/pindou/guide)写了选豆、做图、分板和熨烫；像素文字页可以先打出一版文字图纸；做好的项目可以用分享码发给别人。预览支持缩放，也有 3D 预览和专心拼豆模式。

**图片去哪了**

默认的像素化和配色都在浏览器里算完，图片不会上传。配色用 CIEDE2000 把每个格子对到色卡上最接近的色号。

AI 预处理是可选项，用来在像素化之前先处理原图。风格有清晰增强、线稿、卡通扁平、色块简化、去背景。这一步需要你自己的火山引擎密钥，密钥只存在本机；图片会经本站转发到火山的图像接口，费用记在你的账号上。不用 AI 时，整条流程仍然留在本地。

算法核心拆成了开源包 [@wangdandan810012/bead-core](https://www.npmjs.com/package/@wangdandan810012/bead-core)，说明页在 [dandanhub.vip/pindou/bead-core](https://dandanhub.vip/pindou/bead-core)。

## 蛋蛋工具箱

地址：[dandanhub.vip/toolbox](https://dandanhub.vip/toolbox)

工具箱目前收了两件东西：一件放在 Windows 桌面上，一件在浏览器里打开。

### 蛋蛋便签

Windows 桌面便签与待办，当前版本 v0.1.3，系统要求 Windows 10 / 11，x64。提供安装包，也提供免安装、解压就能跑的便携版。

它适合把今天要记住的事留在桌面上，而不是再开一个重的笔记软件。同一条记录可以当笔记，也可以勾成待办并标记完成。左侧按今天或指定日期看，也可以按标签筛。窗口默认置顶，背景是半透明毛玻璃，透明度能从 0 调到 100%。设置里还可以开关置顶、开机启动，并在简易模式和标准模式之间切换。

数据用 SQLite 存在你的电脑里，不经过账号。

第一次打开时，Windows 可能会弹出安全提示。选「更多信息」，再选继续运行。

下载入口都在工具箱页面：安装包适合长期使用，便携版适合不想写进系统的场景。

### OpenTrace Studio

地址：[dandanhub.vip/opentrace/](https://dandanhub.vip/opentrace/)

给正在做 Agent 或 RAG 的人用的本机调试台。一次运行里，模型说了什么、调了哪个工具、检索到了哪几段、哪一步失败、哪一步特别慢，都可以点开看。

打开之后主要看这些：

- **时间线、瀑布图、调用图。** 按 span 筛选错误和慢点，点进去看入参、出参和状态。
- **RAG 证据。** 检索片段、分数和来源挂在对应的 retriever span 上。答案里的引用可以跳回原文。会话级质检快照会汇总低分片段和引用覆盖情况。
- **回放。** 可以按步骤把一次运行再走一遍，适合自己复盘，也适合讲给同事听。
- **失败诊断。** 把问题归到 Key、网络或下游 HTTP，方便判断该改提示词、改工具，还是改检索。
- **Run Diff。** 换了提示词、模型或工具之后，对比两次会话的耗时、失败点、答案摘要和粗估费用。

数据从两条路进来。一条是页内 Live Run：配好 OpenAI 兼容接口（例如 DeepSeek、OpenAI）之后直接在页面里跑，规划、工具、本地检索和流式回答会边跑边写成 Trace。另一条是导入已有记录：JSONL、OTLP JSON，以及 LangGraph、Dify 的离线导出，进同一套视图。没有 Key 时，可以先加载页面里的离线样例。

会话可以导出 JSONL、生成报告，或做成分享链接发给别人。API Key 只留在当前标签页，会话记录在本机浏览器里。源码以 Apache-2.0 开源：[GitHub](https://github.com/whr810012/opentrace-studio)，镜像在 [Gitee](https://gitee.com/wangdandan810012/opentrace-studio)。

## 加水印

地址：[dandanhub.vip/watermark/](https://dandanhub.vip/watermark/)

给图片、PDF 和视频加上你自己的痕迹，分「打水印」和「识别水印」两页。

**打水印**可以只加看得见的标记，只写隐藏标记，或两种一起写。

看得见的标记支持文字或 Logo。文字用来写品牌、姓名或版权信息，也可以换自定义字体。Logo 建议用透明背景的 PNG 或 WebP。位置可选左上、右上、居中、左下、右下，也可以平铺满版。透明度和大小用滑杆调。内置了几套预设，当前参数也能存成自己的预设，下次直接套用。图片支持批量处理。

隐藏标记叫 DDWM。它写进文件里，画面上不一定看得出来。识别页只认本工具写下的这一种标记，会返回标识、置信度和完整性校验。图片直接扫，PDF 可以按页看，视频按抽样帧看。

文件在浏览器里处理：图片用 Canvas，PDF 用 PDF.js，视频用 FFmpeg WebAssembly。服务器只把页面代码发给你，接触不到文件内容。处理结果留在当前这次打开的页面里。

## 蛋蛋文案

地址：[dandanhub.vip/caption/](https://dandanhub.vip/caption/)

丢进一张图或一段短视频，一次写出三套可以直接发的文案：

- **小红书**：标题、正文、话题
- **抖音**：标题、口播、话题
- **朋友圈**：短的一段

语气可以点选，也可以自己写。预设有探店种草、干货分享、轻松吐槽、氛围感日常、产品开箱。自定义时写具体一点效果更好，例如「周末咖啡店探店」。一次可以放进多个素材。生成之后如果口吻不对，点「再写一套」。

调用使用你自己的火山方舟 Ark API Key。设置里填的是密钥（Secret），模型填官方完整 Model ID，或你自己的接入点 `ep-…`。Key 存在本机。图片会先在本地压缩，再以数据提交；视频不会整段上传，而是在浏览器里抽出 6 到 8 张关键帧，让模型看画面后写文案。费用记在你的方舟账号上。

## dan-ui 组件库

地址：[dandanhub.vip/dan-ui](https://dandanhub.vip/dan-ui)

Vue 3 通用基础 UI 组件库，包名 `@dandan-ui/ui` + `@dandan-ui/theme`。覆盖表单、展示、反馈，以及 AI 对话界面和富文本编辑。主题用 CSS 变量（前缀 `dan-`），支持全量注册和按需引入。

安装：

```bash
pnpm add @dandan-ui/ui @dandan-ui/theme
```

npm：[ui](https://www.npmjs.com/package/@dandan-ui/ui) · [theme](https://www.npmjs.com/package/@dandan-ui/theme)；源码：[GitHub](https://github.com/whr810012/dan-ui)。
